# КВПіА — польові калькулятори

Офлайн PWA для iPhone. Перша версія містить перерахунок шкали й сигналу,
температурні датчики Pt100/Pt1000 і термопари K/J/T, конвертер одиниць та довідку.

## GitHub Pages

1. Завантажте вміст цієї папки в корінь гілки `main` вашого репозиторію. Файл `.nojekyll` має бути в корені поруч з `index.html`.
2. У репозиторії відкрийте **Settings → Pages**. Виберіть **Deploy from a branch → main → /(root)** і збережіть.
3. Дочекайтеся, коли GitHub покаже адресу сайту, і надішліть HTTPS-посилання одержувачу.

Збірка та встановлення залежностей не потрібні. Відносні шляхи підтримують і кореневу адресу, і адресу з назвою репозиторію.

## Встановлення на iPhone

1. Відкрийте HTTPS-посилання в Safari.
2. Натисніть **Поділитися → На початковий екран**. Якщо є перемикач **Відкрити як вебзастосунок**, увімкніть його.
3. Відкрийте КВПіА з нової іконки з доступом до мережі. Дочекайтеся повідомлення **Готово офлайн**.
4. Перевірте роботу в авіарежимі після повного закриття й запуску з іконки. Після очищення даних застосунку повторіть крок 3.

## Методики й перевірка

| Розрахунок | Джерело та перевірка |
| --- | --- |
| Шкала ↔ сигнал | Нормування до інтервалу 0–1, прямий і зворотний перерахунки та контрольні точки кожної характеристики. |
| Pt100/Pt1000 | [IEC 60751:2022](https://webstore.iec.ch/en/publication/63753), [таблиці Omega за DIN EN 60751](https://br.omega.com/omegaFiles/temperature/Z/pdf/z251.pdf). Залежність Каллендара — Ван Дюзена, від −200 до 850 °C. |
| K/J/T | [NIST Monograph 175](https://doi.org/10.6028/NIST.MONO.175). Прямі поліноми ITS-90, обернення бісекцією і поправка холодного спаю. Діапазони K −200…1372 °C, J −210…1200 °C, T −200…400 °C. Контрольні напруги збігаються з табличними в межах 0,0005 мВ. |
| Одиниці | Коефіцієнти й температурні зсуви наведено в `calculations.js`. Позначення US gal відповідає американському галону. |

У наведених допусках і діапазонах ідеться про математичні моделі. Робочий діапазон і точність конкретного датчика визначає його документація.
Результати обчислюються без проміжного округлення й форматуються для показу.

Для перевірки калькуляторів розпакуйте весь ZIP і відкрийте `index.html` подвійним кліком. Для перевірки встановлення й кешування PWA запустіть `python -m http.server 8000` і відкрийте `http://localhost:8000/`.

Автоматичні тести розрахунків запускаються командою `npm test` з Node.js 22 або новішою версією.

Після змін у ресурсах офлайн підвищуйте версію кешу в `sw.js`. Оновлення стає доступним після повного завантаження файлів.
